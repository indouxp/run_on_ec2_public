# 命名基準書

## 1. 概要

### 1.1 目的
本文書は、S3イベント連携によるEC2自動処理で使用するすべてのAWSリソースの命名基準を定義します。すべてのリソース名は `ts-010-` プレフィックスで始まり、2番目のフィールドはAWSオブジェクトタイプを示します。

### 1.2 関連文書

**参照文書**
- 要件定義書（[設計書/要件定義.md](要件定義.md)）
- 基本設計書（[設計書/基本設計.md](基本設計.md)）

## 2. 基本命名規則

### 2.1 パターン
```
ts-010-<オブジェクトタイプ>[-<機能・用途>]-<枝番>
```

### 2.2 例
- `ts-010-lmd-010`
- `ts-010-ec2-010`
- `${BKT_IN}`
- `${BKT_OUT}`
- `ts-010-sns-010`
- `ts-010-role-lambda-010`

## 3. AWSオブジェクトタイプ略語

### コンピューティング
| サービス | 略語 | 例 |
|---------|------|-----|
| Lambda | lmd | `ts-010-lmd-010` |
| EC2 Instance | ec2 | `ts-010-ec2-010` |

### ストレージ
| サービス | 略語 | 例 |
|---------|------|-----|
| S3 Bucket | bkt | `${BKT_IN}`, `${BKT_OUT}` |

### ネットワーキング
| サービス | 略語 | 例 |
|---------|------|-----|
| VPC | vpc | `ts-010-vpc-010` |
| Subnet | subnet | `ts-010-subnet-010` |
| Security Group | sg | `ts-010-sg-010` |
| Internet Gateway | igw | `ts-010-igw-010` |
| Route Table | rt | `ts-010-rt-010` |

### IAM
| サービス | 略語 | 例 |
|---------|------|-----|
| IAM Role | role | `ts-010-role-lambda-010` |
| IAM Policy | policy | `ts-010-policy-010` |
| Instance Profile | profile | `ts-010-profile-010` |

### 通知・メッセージング
| サービス | 略語 | 例 |
|---------|------|-----|
| SNS Topic | sns | `ts-010-sns-010` |

### 監視・ログ
| サービス | 略語 | 例 |
|---------|------|-----|
| CloudWatch Log Group | log | `ts-010-log-lambda-010` |
| CloudWatch Alarm | alarm | `ts-010-alarm-010` |

### イベント
| サービス | 略語 | 例 |
|---------|------|-----|
| EventBridge Rule | rule | `ts-010-rule-stop-ec2-trigger` |

## 4. 枝番・機能用途の命名規則

### 4.1 枝番ルール
- **基本枝番**: `010`（3桁ゼロパディング）
- **増分単位**: 10番単位（010, 020, 030...）
- **最大枝番**: 990まで
- **用途**: 同一タイプのリソースを複数作成する際の識別子

### 4.2 機能・用途指定
- **lambda**: IAMロールなど関連リソース用（例: `ts-010-role-lambda-010`）
- **ec2**: EC2関連リソース用（例: `ts-010-role-ec2-010`）
- **in**: 入力用（例: `${BKT_IN}`）
- **out**: 出力用（例: `${BKT_OUT}`）

## 5. 具体的なリソース命名例

### Lambda関数
```
ts-010-lmd-010                   # EC2起動関数（S3イベントトリガー）
ts-010-lmd-020                   # EC2削除関数（EventBridgeトリガー）
```

### EC2関連
```
ts-010-ec2-010                   # スクリプト実行インスタンス
ts-010-sg-010                    # EC2用セキュリティグループ
ts-010-role-ec2-010              # EC2実行用IAMロール
ts-010-profile-010               # EC2インスタンスプロファイル
```

### S3関連
```
${BKT_IN}                    # 入力専用バケット
${BKT_OUT}                   # 出力専用バケット
```

### IAMロール
```
ts-010-role-lambda-010           # Lambda起動関数用IAMロール
ts-010-role-lambda-020           # Lambda終了関数用IAMロール
ts-010-role-ec2-010              # EC2実行用IAMロール
```

### 通知関連
```
ts-010-sns-010                   # 通知用SNSトピック
```

### 監視・ログ関連
```
ts-010-log-lambda-010            # Lambda関数ロググループ
ts-010-log-ec2-010               # EC2インスタンスロググループ
ts-010-log-system-010            # システムロググループ
ts-010-alarm-010                 # 実行失敗アラーム
```

### EventBridge関連
```
ts-010-rule-stop-ec2-trigger     # EC2停止イベント検知ルール
```

### ファイル命名
定義ファイル・実行シェル・入力ファイル・ログファイル・結果ファイルの名称はすべて任意です。詳細は [設計書/定義ファイル仕様.md](定義ファイル仕様.md) を参照してください。

## 6. 実装時の注意事項

1. **大文字小文字**: すべて小文字を使用
2. **区切り文字**: ハイフン（-）のみ使用
3. **長さ制限**: AWSサービスの制限に準拠
4. **予約語**: AWS予約語の使用を避ける
5. **一意性**: 同一AWSアカウント内で一意になるよう設計

## 7. 命名規則の例外

AWSサービスが自動生成するリソース（ENI、自動生成セキュリティグループなど）は、この命名規則に従わない場合があります。
