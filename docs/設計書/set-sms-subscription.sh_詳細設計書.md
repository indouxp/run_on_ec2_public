# set-sms-subscription.sh 詳細設計書

## 1. 概要

### 1.1 目的

本スクリプトは、SNS トピック（`ts-010-sns-010`）に SMS サブスクリプションを設定します。引数で指定した電話番号に対して SNS サブスクリプションリクエストを送信します。E メールとは異なり、SMS の場合は確認プロセスなしで即時有効になります。

## 2. 実行環境

- 実行場所: `infra/` ディレクトリ
- 必要コマンド: aws cli、awk
- AWS 認証: `source assume-role.sh`（`ts-010-role-exec` を AssumeRole）または `AWS_PROFILE=ts-usr-admin`

---

## 3. 前提条件

- SNS トピック（`ts-010-sns-010`）が作成済みであること（`mk-sns-topic.sh` 実行済み）
- 指定する電話番号が E.164 形式（`+819012345678`）であること

---

## 4. 入力

### 4.1 スクリプト内固定値

| 変数名 | 内容 | 値 |
|:---|:---|:---|
| `TOPIC_NAME` | サブスクリプションを設定する SNS トピック名 | `ts-010-sns-010` |

### 4.2 引数

| 引数 | 説明 | 例 |
|:---|:---|:---|
| `$1` | 通知先電話番号（必須、E.164 形式） | `+819012345678` |

> **形式**: `+819` から始まり、続けて数字のみを指定してください。

---

## 5. 処理フロー

### 初期化

1. ログファイル（`set-sms-subscription.sh.log`）へのリダイレクトを設定する（`exec >> LOG_PATH 2>&1`）。
2. 第 1 引数（`$1`）の有無を確認する。引数がない場合はエラーメッセージを表示して `exit 1` で終了する。
3. `PHONE_NUMBER` に第 1 引数を設定する。

### SNS トピック ARN 取得

4. `aws sns list-topics` でトピック一覧を取得し、`grep "$TOPIC_NAME"` と `awk` で ARN を抽出する。
5. ARN が取得できない場合（空文字の場合）はエラーメッセージを表示して `exit 1` で終了する。

### サブスクリプション設定

6. `aws sns subscribe` で SMS サブスクリプションを設定する:
   - `--topic-arn`: 取得した ARN
   - `--protocol sms`
   - `--notification-endpoint`: 指定した電話番号

## 7. エラーハンドリング

- スクリプト先頭に `set -euo pipefail` を設定し、コマンド失敗・未定義変数参照・パイプエラーで即時終了する。
- 引数が指定されていない場合は `exit 1` で終了する。
- SNS トピックが見つからない場合は `exit 1` で終了する。
- すべての処理ログは `set-sms-subscription.sh.log` に記録される。

> **注意**: SMS 送信には AWS SNS の SMS 機能が有効であることが必要です。また、電話番号は E.164 形式（国番号から始まる形式、例: `+819012345678`）で指定してください。
