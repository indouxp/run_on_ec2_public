# mk-sg-ssh.sh 詳細設計書

## 1. 概要

### 1.1 目的

本スクリプトは、既存のセキュリティグループ（`ts-010-sg-010`）に SSH（TCP ポート 22）インバウンドルールを追加します。許可 IP アドレスはスクリプト実行時点のグローバル IP アドレスを自動取得します。既存の SSH ルールが存在する場合は削除してから再追加します。

設定するリソース:
- セキュリティグループ `ts-010-sg-010` への SSH インバウンドルール追加
  - プロトコル: TCP
  - ポート: 22
  - 許可 CIDR: 実行時のグローバル IP アドレス `/32`

## 2. 実行環境

- 実行場所: `infra/` ディレクトリ
- 必要コマンド: aws cli、curl、jq
- AWS 認証: `source assume-role.sh`（`ts-010-role-build` を AssumeRole）

---

## 3. 前提条件

- VPC（`ts-010-vpc-010`）が作成済みであること
- セキュリティグループ（`ts-010-sg-010`）が作成済みであること（`mk-sg.sh` 実行後）
- インターネット接続が可能であること（グローバル IP 取得のため）

## 4. 入力

### 4.1 設定ファイル（config.sh）

| 変数名 | 説明 | 例 |
|:---|:---|:---|
| `VPC_NAME` | セキュリティグループが属する VPC の名前タグ | `ts-010-vpc-010` |

### 4.2 引数

コマンドライン引数はありません。

## 5. 処理フロー

### 初期化

1. `config.sh` を読み込み、環境変数を設定する。
2. 作業用一時ディレクトリ（`mk-sg-ssh.sh.src`）を作成する。
3. `trap` を設定し、ERR / INT / TERM シグナル発生時に `term()` を呼び出して一時ディレクトリを削除し、`exit 1` で終了する。EXIT シグナルでも `term()` を呼び出す。
4. ログファイル（`mk-sg-ssh.sh.log`）へのリダイレクトを設定する（`exec >> LOG_PATH 2>&1`）。

### `confirm_sg()` — 実行前後の確認

5. `aws ec2 describe-vpcs` で VPC ID を取得する。
6. `aws ec2 describe-security-groups` で対象セキュリティグループの GroupId と IpPermissions を表示する。

### `add_ssh_rule()` — SSH ルール追加処理

7. `aws ec2 describe-vpcs` で VPC ID を取得する。VPC が見つからない場合はエラー終了する。
8. `aws ec2 describe-security-groups` でセキュリティグループ ID を取得する。SG が見つからない場合はエラー終了する。
9. `curl -s ifconfig.me` でスクリプト実行元のグローバル IP アドレスを取得する。取得失敗の場合はエラー終了する。
10. 既存の SSH ルール（TCP ポート 22）を `jq` で抽出する。
    - 既存ルールが存在する場合: `aws ec2 revoke-security-group-ingress` で削除する。
11. `aws ec2 authorize-security-group-ingress` で新しいグローバル IP アドレス（`/32`）から TCP ポート 22 への受信を許可するルールを追加する。

### メイン処理の流れ

12. 実行前に `confirm_sg()` を呼び出してリソース状態を記録する。
13. `add_ssh_rule()` を呼び出して SSH ルールを追加する。
14. 実行後に `confirm_sg()` を再度呼び出して結果を確認する。

## 7. エラーハンドリング

- スクリプト先頭に `set -euo pipefail` を設定し、コマンド失敗・未定義変数参照・パイプエラーで即時終了する。
- `trap 'term; exit 1' ERR INT TERM` により、異常終了時は作業用一時ディレクトリを自動削除する。
- `trap 'term' EXIT` により、正常終了時も一時ディレクトリを削除する。
- VPC / SG が見つからない場合、またはグローバル IP 取得に失敗した場合は `exit 1` で終了する。
- すべての処理ログは `mk-sg-ssh.sh.log` に記録される。

> **注意**: SSH ルールはスクリプト実行時点の IP アドレスに固定されます。IP アドレスが変更された場合は本スクリプトを再実行してください。
