# run.sh 詳細設計書

## 1. 概要

### 1.1 目的
本ドキュメントは、`user_data_template.sh` によって実行されるユーザー定義スクリプト `run.sh` の詳細な設計を定義します。

このスクリプトの主な責務は、入力された動画ファイル（`.MOV`）を `.mp4` 形式に変換することです。副次的なタスクとして、変換処理中のシステムアクティビティ（CPU、メモリ、ディスクI/Oなど）を記録し、パフォーマンスの傾向を分析するためのログを生成します。

### 1.2 関連文書

**参照文書**
- 要件定義書（[設計書/要件定義.md](要件定義.md)）

## 2. 入力

### 2.1 引数

- スクリプトは、コマンドライン引数としてtar.gzアーカイブのパス（またはワイルドカードを含むパターン）を受け取ります。（`$@`）
- 例: `run.sh *.tar.gz`

### 2.2 ファイル

- 引数で指定されたtar.gzアーカイブ。このアーカイブ内には、変換対象の `.MOV` ファイルが含まれていることを前提とします。

## 3. 出力

### 3.1 ファイル

- **`.mp4` ファイル**: 各 `.MOV` ファイルに対応する変換後の動画ファイル。
- **`run.log`**: スクリプト全体の標準出力・標準エラー出力を記録したメインのログファイル。呼び出し元の `user_data_template.sh` がリダイレクトを管理します。
- **`simple-act.log`**: バックグラウンドで定期的に取得された、システムのパフォーマンス指標（CPU使用率、メモリ使用量など）を記録したアクティビティログ。

## 4. 依存関係

本スクリプトは、実行されるEC2インスタンス（AMI）に以下のツールがプレインストールされていることを前提とします。

- `curl`: `ffmpeg` のバイナリをダウンロードするために使用します。
- `tar`: ダウンロードしたアーカイブを展開するために使用します。入力となるtar.gzアーカイブの展開にも使用します。
- `sysstat` パッケージ: `mpstat` および `iostat` コマンドを提供し、システムアクティビティを監視するために必要です。

**注記**:
- `ffmpeg` 本体は、スクリプト自身が `johnvansickle.com` から静的ビルドをダウンロードしてインストールするため、AMIにプレインストールされている必要はありません。
- `pigz` は、スクリプト自身が `yum install -y pigz` でインストールします。

## 5. 処理フロー

1. **初期設定**
    - `set -e -u -o pipefail` を設定し、エラー発生時に即座にスクリプトが終了するようにします。
    - `timedatectl set-timezone Asia/Tokyo` を使用して、システムのタイムゾーンを `Asia/Tokyo` に設定します。
    - `lscpu`, `free -h`, `lsblk`, OSリリース情報などで初期のシステム情報をログに出力します。
    - IMDSメタデータからインスタンスタイプを取得して出力します。

2. **システム監視の開始**
    - システムアクティビティ（`uptime`, `mpstat`, `iostat` など）を10秒ごとに記録する無限ループのシェルスクリプトを `/tmp/simple-act` に生成します。
    - この監視スクリプトをバックグラウンドで実行 (`&`) し、出力を `simple-act.log` に保存します。そのプロセスIDを後で終了させるために変数 `PID` に保持します。

3. **FFmpegのインストール**
    - `/usr/local/bin` に移動し、`curl` を使用して `ffmpeg` の静的ビルドのアーカイブを `johnvansickle.com` からダウンロードします。
    - `tar -xJf` でアーカイブを展開し、`ffmpeg` バイナリを `/usr/local/bin` にコピーして実行権限を付与します。

4. **pigzのインストール**
    - `sudo yum install -y pigz` を使用して `pigz` をインストールします。

5. **入力ファイルの展開**
    - ホームディレクトリ（`cd`）に移動します。
    - `for PIGZ in "$@"; do pigz -dc "$PIGZ" | tar -xf -; done` コマンドで、引数として渡された全てのtar.gzアーカイブをカレントディレクトリに展開します。

6. **動画変換処理**
    - `for` ループを使用して、カレントディレクトリ内の全ての `.MOV` ファイルを順番に処理します。
    - 各 `.MOV` ファイルに対して、出力ファイル名となる `.mp4` のパスを生成します。
    - `ffmpeg -i <入力.MOV> <出力.mp4>` コマンドを実行して動画形式を変換します。

7. **システム監視の終了**
    - `sleep 10` で短時間待機した後、`kill $PID` コマンドでバックグラウンドで実行していたシステム監視スクリプトを終了させます。

8. **完了**
    - 最終的な完了時刻をログに出力して、スクリプトを正常終了します。

## 6. エラーハンドリング

- スクリプト冒頭の `set -e -u -o pipefail` により、`ffmpeg` のインストール失敗、tar.gz展開の失敗、`ffmpeg` による変換失敗など、いずれかのコマンドがエラー（非ゼロの終了コード）を返した時点で、スクリプト全体が即座に異常終了します。
- この異常終了は、親スクリプトである `user_data_template.sh` によって検知され、その結果として「FAILED」の通知が送信される仕組みとなっています。
