# mk-keypair.sh 詳細設計書

## 1. 概要

### 1.1 目的

本スクリプトは、EC2 インスタンスへの SSH 接続に使用するキーペア（`ts-010-keypair`）を作成します。既存の同名キーペアが存在する場合は削除してから再作成します。秘密鍵ファイルはプロジェクトルートに保存し、パーミッション 400 を設定します。

作成するリソース:
- AWS EC2 キーペア（名前: `ts-010-keypair`）
- 秘密鍵ファイル: `<プロジェクトルート>/ts-010-keypair.pem`（パーミッション 400）

## 5. 処理フロー

### 初期化

1. `config.sh` を読み込み、環境変数を設定する。
2. 作業用一時ディレクトリ（`mk-keypair.sh.src`）を作成する。
3. `trap` を設定し、ERR / INT / TERM シグナル発生時に `term()` を呼び出して一時ディレクトリを削除し、`exit 1` で終了する。EXIT シグナルでも `term()` を呼び出す。
4. ログファイル（`mk-keypair.sh.log`）へのリダイレクトを設定する（`exec >> LOG_PATH 2>&1`）。
5. キーペア名（`ts-010-keypair`）と秘密鍵ファイルパス（`${PROJECT_ROOT}/ts-010-keypair.pem`）を設定する。

### `confirm_keypair()` — 実行前後の確認

6. `aws ec2 describe-key-pairs` でキーペアの KeyName と KeyFingerprint を表示する（存在しない場合はその旨を表示）。

### `make_keypair()` — キーペア作成処理

7. `aws ec2 describe-key-pairs` で既存キーペアの有無を確認する。
8. 既存キーペアが存在する場合:
   - `aws ec2 delete-key-pair` でキーペアを削除する。
9. 既存の秘密鍵ファイル（`.pem`）がある場合は `rm -f` で削除する。
10. `aws ec2 create-key-pair` で新規キーペアを作成し、秘密鍵（KeyMaterial）をプロジェクトルートの `.pem` ファイルに保存する。プロジェクトタグを付与する。
11. `chmod 400` で秘密鍵ファイルのパーミッションを所有者のみ読み取り可能に設定する。

### メイン処理の流れ

12. 実行前に `confirm_keypair()` を呼び出してリソース状態を記録する。
13. `make_keypair()` を呼び出してリソースを作成する。
14. 実行後に `confirm_keypair()` を再度呼び出して結果を確認する。

## 7. エラーハンドリング

- スクリプト先頭に `set -euo pipefail` を設定し、コマンド失敗・未定義変数参照・パイプエラーで即時終了する。
- `trap 'term; exit 1' ERR INT TERM` により、異常終了時は作業用一時ディレクトリを自動削除する。
- `trap 'term' EXIT` により、正常終了時も一時ディレクトリを削除する。
- すべての処理ログは `mk-keypair.sh.log` に記録される。

> **注意**: キーペアを再作成すると秘密鍵が新しくなります。再作成後は `ts-010-keypair.pem` を安全な場所に保管してください。旧キーでの SSH 接続はできなくなります。
