## 備考

### tc-030
- MY_SRC_DIR (./${TARGET_SCRIPT}.src) の位置にファイルを touch して mkdir を失敗させる
- AWS API 呼び出し前に exit するため assume-role 不要

### tc-040
- 前処理でキーペアを作成後に mk-keypair.sh を実行
- 既存キーペアを削除して再作成することを確認

### tc-060
- 検証項目: AWS上にキーペア存在 / .pem ファイル存在 / パーミッション 400

### tc-070
- describe-key-pairs は 2>/dev/null で抑制されるため confirm_keypair() は継続するが、make_keypair() の create-key-pair で UnauthorizedOperation → set -euo pipefail により exit
- .pem ファイルが削除された後に権限エラーとなるため、tc-070 実行後は .pem が消えた状態になる点に注意
