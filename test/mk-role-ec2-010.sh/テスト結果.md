## 備考

### MY_SRC_DIR チェック位置
`mk-role-ec2-010.sh` の MY_SRC_DIR チェックはAWS呼び出しより前に実行されるため、
tc-030 は AWS_PROFILE 不要（mk-role-lambda-010.sh と同様）。

### tc-040 前処理の設計
本番ロール `ts-010-role-ec2-010` に想定外のポリシー（`ts-010-policy-ec2-job-execution`）が
アタッチされていたため、`make_role()` 内の `delete-role` が失敗した。
対策として tc-040 前処理では「全ポリシーを列挙してデタッチ・削除後、
`make_role()` が期待する既知の状態でロールを再作成」する方式に変更した。

### スクリプトのバグ修正
テスト実施中に `confirm_role()` の JMESPath クエリでバグを発見し修正した。

**修正前**: `Roles[?starts_with(RoleName, \"${PRJ_PREFIX}-role\")]`
→ サービスリンクロール等の RoleName が null のロールが含まれると失敗

**修正後**: `Roles[?RoleName && starts_with(RoleName, '${PRJ_PREFIX}-role')]`
→ null チェックを追加して安全に処理
