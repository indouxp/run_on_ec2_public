## 備考

### tc-030
- MY_SRC_DIR (./${TARGET_SCRIPT}.src) の位置にファイルを touch して mkdir を失敗させる
- AWS API 呼び出し前に exit するため assume-role 不要

### tc-040
- 前処理でSubnetを作成後に mk-subnet.sh を実行
- 既存Subnetを削除して再作成することを確認

### tc-060
- 検証項目: SubnetId存在 / CIDRブロック(10.0.1.0/24) / VPC所属 / Nameタグ / State(available)

### tc-070
- `ec2:DescribeSubnets` および `ec2:DescribeVpcs` が UnauthorizedOperation
- confirm_subnet() の `|| echo "..."` により exit せず継続したが、make_subnet() の describe-vpcs で set -euo pipefail により exit
