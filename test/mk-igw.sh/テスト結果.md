## 備考

### tc-020
- sed で `exec >> "${LOG_PATH}" 2>&1` を `/notexist/notexist.log` に置換
- `&` が sed の特殊文字として展開されるため diff 表示は乱れるが、`/notexist/notexist.log` 部分は正しく置換されており動作に問題なし

### tc-030
- MY_SRC_DIR を持たないため、config.sh の `VPC_NAME` を `vpc-notexist` に sed 書き換えて実行
- 実VPCを削除せずに「親VPC が見つかりません」エラーを再現

### tc-040
- 前処理でIGWを作成・アタッチ後に mk-igw.sh を実行
- 既存IGWをデタッチ・削除して再作成することを確認

### tc-070
- `ec2:DescribeInternetGateways` および `ec2:DescribeVpcs` が UnauthorizedOperation
- confirm_igw() の `|| echo "..."` により exit せず継続したが、create_and_attach_igw() の describe-vpcs で set -euo pipefail により exit
