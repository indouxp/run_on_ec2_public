## 備考

### tc-030
- MY_SRC_DIR (./${TARGET_SCRIPT}.src) の位置にファイルを touch して mkdir を失敗させる
- AWS API 呼び出し前に exit するため assume-role 不要（mk-sg.sh と異なりトップレベルの AWS 呼び出しなし）

### tc-040
- 前処理で SSHルール（ポート22）を追加後に mk-sg-ssh.sh を実行
- 既存ルールを削除して再追加することを確認

### tc-060
- 検証項目: ポート22 TCP ルール存在 / CIDR（グローバルIP/32）一致

### tc-070
- confirm_sg() の describe-vpcs で UnauthorizedOperation → set -euo pipefail により即時 exit
