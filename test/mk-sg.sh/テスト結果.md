## 備考

### tc-030
- MY_SRC_DIR (./${TARGET_SCRIPT}.src) の位置にファイルを touch して mkdir を失敗させる
- mk-sg.sh はトップレベル（exec >> LOG 直後）で VPC_ID を取得するため、MY_SRC_DIR チェック前に AWS API が呼ばれる
- そのため他のスクリプトの tc-030 と異なり assume-role が必要

### tc-040
- 前処理でSGを作成後に mk-sg.sh を実行
- 既存SGを削除して再作成することを確認

### tc-060
- 検証項目: GroupId存在 / VPC所属 / インバウンドルール数(0)

### tc-070
- スクリプトのトップレベル VPC_ID 取得（describe-vpcs）で UnauthorizedOperation → set -euo pipefail により即時 exit
